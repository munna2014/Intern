# TextUtils

A React-based text utility application that provides various text manipulation features.

## Features

- **Convert to Uppercase** - Transform your text to uppercase
- **Convert to Lowercase** - Transform your text to lowercase
- **Copy to Clipboard** - Copy text with one click
- **Remove Extra Spaces** - Clean up unnecessary whitespace
- **Clear Text** - Reset the text area
- **Text Summary** - View word count and character count
- **Dark/Light Mode** - Toggle between dark and light themes
- **Live Preview** - See your text changes in real-time

## Tech Stack

- React.js
- React Router DOM
- Bootstrap

## Installation

1. Clone the repository
```bash
git clone https://github.com/munna2014/Intern.git
cd Intern
git checkout TextUtils
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
